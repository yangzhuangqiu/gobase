# PR Checklist（Testing）

## 1) 风险分级（必填）

- [ ] 本次变更风险级别已标注：`P0` / `P1` / `P2`
- [ ] 风险判定理由已写明（为什么是该级别）

## 2) 去重检查（必填）

- [ ] 已执行同类测试检索，确认不是重复造例
- [ ] 检索命令（粘贴原命令）：
  - `rg -n "TestUseCase.*<场景关键字>" <module>`
  - `rg -n "<错误码|stage=|reason=>关键字" <module>`
- [ ] 若存在同类测试：本次仅补“缺失断言”，未复制整例

## 3) 测试覆盖（必填）

- [ ] 已补/已更新 `usecase_test.go`（调用链冒烟，若涉及公开行为）
- [ ] 已补/已更新 `*_test.go`（边界矩阵/并发/错误语义，若涉及内部语义）
- [ ] 若修复线上问题：已新增回归测试并说明“历史问题 -> 断言点”

## 4) 执行证据（必填）

- [ ] 已执行变更模块 `test + vet`
- [ ] 已执行错误语义门禁脚本并通过：
  - `& ./scripts/check-error-semantic.ps1`
- [ ] 已执行命令与结果摘要已贴在 PR（通过/失败原因）
- [ ] 如涉及集成链路：`integration` 结果已贴（或说明 Skip 原因）
- [ ] 如涉及并发路径：`race` 结果已贴（或说明当前环境限制）

## 5) 文档一致性（按需）

- [ ] 行为语义变化已同步到设计/测试文档
- [ ] 场景到测试映射已更新（若新增关键场景）
